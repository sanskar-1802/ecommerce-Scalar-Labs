# 🛒 E-Commerce Web Application

A full-stack e-commerce application built using modern web technologies.
It allows users to browse products, add items to cart or wishlist, and place orders with a smooth and responsive UI.

---

## 🚀 Tech Stack

### Frontend

* React.js
* Axios
* React Router DOM
* CSS (Inline Styling)

### Backend

* Node.js
* Express.js
* MySQL

---

## ✨ Features

### 🏠 Product Listing

* Display products in responsive grid layout
* Search products by name
* Filter products by category

### 📦 Product Details

* Image carousel for multiple product images
* Product description and specifications
* Stock availability status
* Add to Cart & Buy Now functionality

### 🛒 Shopping Cart

* View all added items
* Update quantity dynamically
* Remove items from cart
* View total price calculation
* Buy Now option directly from cart

### ❤️ Wishlist

* Add products to wishlist
* View wishlist items
* Move items from wishlist to cart
* Remove items from wishlist

### 🧾 Order System

* Checkout page with address input
* Order placement functionality
* Order confirmation page with order ID
* Order history tracking

### 🔐 Authentication

* User Signup
* User Login
* Session handling using localStorage

### 🎨 UI/UX

* Clean and modern UI
* Responsive design (Mobile, Tablet, Desktop)
* Toast notifications for user actions

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sanskar-1802/ecommerce-Scalar-Labs.git
cd ecommerce_Scalar_labs
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
